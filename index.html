The uploaded book image is already included as the tracking marker. MindAR needs a compiled .mind target file before scanning.

  1. Choose Compile marker below. The browser will make and download targets.mind.
  2. Move that file into the app's assets folder.
  3. Add your model using this exact path:

assets/model.glb

GLB is the easiest web-ready format. The placeholder creature is replaced automatically when the file exists. For camera access, open this site over HTTPS or localhost and allow camera permission.
